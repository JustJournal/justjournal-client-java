justjournal-client-java
=======================

JustJournal Java (Swing) Client

Requirements
------------

Java 17 or later is required to run the client.

Running
-------

Build the jar, which includes the libraries the client needs:

    ./mvnw package

Then start the client:

    java -jar target/javajj-1.3.jar
